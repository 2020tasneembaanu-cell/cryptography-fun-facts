# Cryptography Fun Facts 🔐

This project is a simple and interactive way to explore interesting facts about cryptography — the art of securing information.  
It introduces basic encryption and decryption concepts in a fun, beginner-friendly format.

## 🧠 Features
- Displays fun facts about cryptography.  
- Demonstrates simple ciphers (like Caesar Cipher or substitution).  
- Helps beginners understand how messages are encoded and decoded.  

## 💻 Technologies Used
- Python  
- Basic command-line interface (CLI)  
- Optional: HTML/CSS (if displayed on a web page)
